# Умный Уход 🌿

Telegram-бот для подбора уходовых средств по типу кожи, проблемам и бюджету.

## Возможности
- Пошаговый подбор ухода
- Сохранение профиля
- PRO-режим (расширенный подбор)
- Поддержка популярных брендов

⚠️ Бот не заменяет консультацию дерматолога.

## Запуск
```bash
pip install -r requirements.txt
